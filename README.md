# Eightfold Helper

**Which parts of the path need your attention?** A free, private self-check on the eight factors of the Noble Eightfold Path, as the early Buddhist discourses define them. A quick check (tick the factors you feel steady in) or a full check (27 statements drawn from the definitions in SN 45.8) draws your result as an eight-spoked Dharma wheel and suggests practices for the factors that need attention, each grounded in a quoted passage. A short online book gives a chapter to each factor.

Live: https://theguysaccount.github.io/wheel-of-dharma-eightfold-helper/

All quotations are Bhikkhu Sujato's translations from SuttaCentral, dedicated to the public domain (CC0), taken word for word by segment and re-checked weekly. The site is a reflection aid: not a measure of spiritual progress, not a substitute for a teacher, not affiliated with any Buddhist organisation, and not medical or psychological advice.

## What's here

- `site/data/factors.json`: the eight factors (statements, practices, chapter text, questions). `sources.json`: the passages quoted (segment ids). `quotes.json`: their text, generated by `pipeline/sources.py`.
- `site/assets/core.js`: scoring, focus, result links, wheel geometry. `helper.js`: the self-check page.
- `pipeline/build.py`: builds `dist/`, generating the chapters and the sources page (Python stdlib).
- `scripts/e2e.mjs` + `cdp.mjs`: end-to-end test in headless Chrome. `check_live.py`: live pages and staleness.

## Run, test, deploy

```bash
python3 pipeline/build.py && python3 -m http.server -d dist 8000   # http://127.0.0.1:8000/
node --test tests/js/*.test.mjs            # logic and content tests (Node 22+)
python3 -m unittest discover -s tests      # build tests
node scripts/e2e.mjs                       # end-to-end against dist/ (Chrome)
python3 pipeline/sources.py --verify       # quotations still match SuttaCentral, and are CC0
```

Deploys run from GitHub Actions on every push to `main`. See [OPERATIONS.md](OPERATIONS.md).
